# 🔭 WikiKnowledge Explorer

Explore Wikipedia knowledge, discover connected topics, and navigate through related information.

## 📌 Project Overview

WikiKnowledge Explorer is an interactive prototype built using the **Wikimedia Structured Wikipedia Dataset**.

The application allows users to explore a Wikipedia article, view its structured sections, and discover related information connected through the article.

For this prototype, the article **ISRO (Indian Space Research Organisation)** is explored.

## 🎯 Objective

The objective of WikiKnowledge Explorer is to make structured Wikipedia information easier to explore by organizing article content into sections and presenting related information through an interactive interface.

## ✨ Features

- 📄 Article overview
- 📚 Explore structured article sections
- 🔗 Discover related information
- 🔎 Search connected topics
- 🌐 Open related Wikipedia articles
- 🆔 Display the main Wikidata entity
- 📊 Display article and connection statistics
- 🖥️ Interactive user interface

## 🗂️ Dataset

This project uses the **Wikimedia Structured Wikipedia Dataset**.

The application uses structured information available in the dataset, including:

- Article name
- Description
- Abstract
- Main entity
- Article sections
- Links to related information

Related connections are extracted from links present in the structured article content.
